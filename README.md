# The Effect

Website project for **The Effect**, an all-natural, texture-based hair clay.

- **Owner:** Tim Medina (barber)
- **Product:** All-natural texture clay for hair
- **Started:** November 2026

## Folder layout

| Folder | What goes here |
|---|---|
| `site/` | The website itself (`index.html`, styles, scripts, images) |
| `brand/logo/` | Logo files (SVG, PNG) |
| `brand/photos/` | Product shots, Tim cutting hair, before/after styles |
| `content/` | Website copy: about, product details, ingredients, FAQ |
| `notes/` | Planning notes, meeting notes with Tim, to-dos |
